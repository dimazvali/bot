# Handoff: photo.dimazvali.com — редизайн v2

## Overview
Редизайн фотопортфолио photo.dimazvali.com: публичная часть (главная, серия, фото, мобильная версия, поп-ап «Хотите съёмку?») и клиентский режим съёмки (галерея с выбором кадров, экран пароля). Направление развивает эксперимент photo2 (Oswald / Lora / JetBrains Mono) и решает «точки роста» из описания: вступление и витрина серий на главной, единая панель фильтров, action-card «подписаться», «Обо мне» в навигации, визуальное отделение клиентского режима.

## About the Design Files
Файлы в пакете — **дизайн-референсы, сделанные в HTML**: прототипы, показывающие вид и поведение, а не продакшн-код. Задача — **воспроизвести их в существующем коде сайта** (Pug-шаблоны + CSS + клиентский JS), используя его паттерны. Существующие URL, SEO-разметку (JSON-LD, hreflang, canonical, OG), аналитику, soft-навигацию, клавиши и логику тем **не менять** — меняется только визуальный слой и добавляются новые блоки.

Открыть: `Photo Portfolio v2.dc.html` в браузере (рядом должны лежать `support.js`, `Sidebar.dc.html`, `gallery-data.js`). Холст панорамируется/масштабируется. Экраны помечены 5a–5g.

## Fidelity
**High-fidelity** по цветам, типографике, отступам и раскладке. Копирайт — черновой, двуязычие RU/EN нужно сохранить (EN-версии строк не нарисованы — переводить существующими ключами). Данные макета — реальный экспорт; **съёмка, лица, имена, комментарии и подборки в 5e — выдуманы** (в экспорте их нет).

## Interactions & Behavior
Всё существующее поведение сохраняется (клавиши Esc/←/→, свайпы, soft-навигация, предзагрузка, лайтбокс/панорамы, шафл, презентация 5 с, карта Leaflet, sessionStorage выбора, cookie IG-промо, авто-тема). Новое:
- Единая панель фильтров: тип/цвет/тег комбинируются, повторный клик снимает фильтр; цвет может вести на `/color/:family`, тег — на `/tag/:slug` (сохранить URL-ы для SEO).
- Sticky-полосы: фон с `backdrop-filter: blur(8px)`.
- Ховер-подписи: плавное появление ~180ms ease; изображения — существующие shimmer + fade-in.
- Кнопки без скругления; hover — инверсия заливки (ink ↔ крем).
